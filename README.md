# MediKiosk (SwasthSethu) — Interactive Prototype

A scripted, multilingual patient-intake kiosk prototype. No backend, no API keys,
no database — everything runs in the browser. Built to demo the interaction
model (voice in, voice out, live language switching) before wiring in a real
AI + Bhashini later.

## How to run it

1. Install [Node.js](https://nodejs.org) if you don't have it already (any
   recent LTS version works).
2. Open this folder in a terminal (or use VS Code's built-in terminal:
   `Terminal → New Terminal`).
3. Install dependencies:
   ```
   npm install
   ```
4. Start it:
   ```
   npm run dev
   ```
5. Open the URL it prints (usually `http://localhost:5173`) in **Google
   Chrome** — the speech features are built on Chrome's Web Speech API and
   work best there. Other browsers may not support voice input at all (the
   app falls back to a text box if so).

## What's real vs. simulated

- **Real:** the browser actually speaks the questions out loud
  (`SpeechSynthesis`) and actually listens to and transcribes your voice
  (`SpeechRecognition`) — no external API, completely free, built into Chrome.
- **Scripted:** the 5 interview questions are fixed (not generated by an AI),
  and the final summary is pre-written demo data, not a real AI-generated
  summary. This is intentional — get the interaction feel right first.
- **Simulated:** the document scan step is a timed animation, not real OCR.

## Where to plug in the real AI later

Open `src/data/script.js` — the `QUESTIONS` array and `DEMO_SUMMARY` object
are the only things that need to change to go from "scripted" to "real AI."
Everything else (the speech hook, the screens, the language switching) stays
exactly as-is; you'd just replace the fixed question list with a live call to
Gemini/Claude/GPT that generates the next question based on what the patient
just said.

## Project structure

```
src/
  App.jsx                    → screen state machine (which screen is showing)
  useSpeech.js                → wraps the browser's voice APIs
  data/script.js              → ALL text content (3 languages) + the question script
  components/
    LanguageSwitcher.jsx      → the always-visible language pills
    LanguageScreen.jsx        → screen 1
    ConsentScreen.jsx         → screen 2
    ConversationScreen.jsx    → screen 3 (the core interview)
    DocScanScreen.jsx         → screen 4
    SummaryScreen.jsx         → screen 5
  styles.css                  → all styling (teal/marigold theme, animations)
```

## Try the multilingual switch live

Once you're in the interview screen, tap a different language pill at the
top — the SAME question re-displays and re-speaks instantly in the new
language, without restarting the conversation. This is the feature to
demo live for judges.
